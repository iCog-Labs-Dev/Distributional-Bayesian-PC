# Distributional Bayesian Predictive-Coding Neural Network (BPCN)

This project implements a Bayesian neural network embedded in a predictive-coding framework where uncertainty is represented at two levels: local posteriors over latent states and a layerwise posterior over weights. The key departure from standard predictive coding is in the M-step — rather than optimizing an expected-log-likelihood objective, the weight posterior is updated via a distributional moment-matching projection so that the layer's predictive distribution matches the frozen latent posterior in both mean and variance. This creates a direct route from unresolved latent variance to weight posterior variance, meaning the network can express genuine epistemic uncertainty about the learned mapping rather than collapsing to a confident average.

The practical motivation is robustness to conflict, ambiguity, and out-of-distribution data. When two observations with nearly identical internal representations demand incompatible targets, a deterministic or standard Bayesian model tends to average them and grow confident with more data. This model instead allows the weight posterior to remain broad or widen in the relevant directions, reflecting that the conflict is epistemic. The same mechanism generalizes to OOD inputs: because predictive variance explicitly depends on weight uncertainty, presynaptic latent variance, and residual noise, novel inputs that cannot be confidently explained by any single mapping naturally produce higher predictive uncertainty without requiring a separate OOD detector.
